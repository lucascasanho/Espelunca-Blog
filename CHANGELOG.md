# Changelog

## 1.0.0 — 2026-09-05

- Primeira versão funcional do tema Espelunca Blog.
- Block Theme nativo com `theme.json`.
- Home editorial responsiva com destaque automático para a publicação mais recente.
- Templates para artigo, página, arquivo, busca e 404.
- Cabeçalho e rodapé editáveis pelo Site Editor.
- Paleta Espelunca e modo escuro automático via preferência do sistema.
- Variação de estilo manual “Noite”.
- Pattern de chamada para `espelunca.social`.
- Nenhum plugin ou page builder obrigatório.
